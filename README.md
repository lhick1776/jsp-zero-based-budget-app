\# Zero-Based Budgeting App (Java / JSP)

A web-based personal finance application built on the Zero-Based Budgeting methodology (`Income - Allocations = $0.00`).



\## Planned Architecture

\- \*\*Backend:\*\* Java POJOs \& Servlets (`ZeroBasedBudget`, `BudgetCategory`)

\- \*\*Frontend:\*\* Jakarta Server Pages (JSP) \& HTML/CSS (Module 4)
